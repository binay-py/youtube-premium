# PremiumTube

This folder is the extension itself — load **this** directory with **Load unpacked** in `chrome://extensions`.

Full documentation lives in the [repository README](../README.md): features, install, architecture, permissions and known issues.

> The previous version of this file described a freemium model with a $2.99
> paid tier gating ad-skip and UI features. That model was dropped — every
> feature is free and enabled by default, and no payment or unlock code path
> exists in the shipped code. It was removed rather than updated so there is
> only one description of the project to keep in sync.
